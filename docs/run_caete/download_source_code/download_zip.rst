Download zip source code **(recommended)**
==========================================

**1) Access** `CAETÊ source code on GitHub <https://github.com/LabTerra/CAETE/>`_.

----

**2) Select a branch you want to download**

.. figure:: ../../img/github_select_branch.png
   :align: center
   :width: 60%
   :figclass: align-center

   **Selecting a branch on Github.**

----

**3) Download zip source code**

.. figure:: ../../img/github_download_zip.png
   :align: center
   :width: 60%
   :figclass: align-center

   **Download zip source code.**

----

**4) Extract the CAETÊ source code zip file on a folder you choose in your computer.**
